# MindMate — Chatbot Demo

A lightweight browser page that embeds a hosted Chatbase chatbot in a simple, distraction-free layout. The chatbot itself is served by Chatbase; this repository contains the page wrapper, not the hosted model or service.

## Run locally

Open [index.html](index.html) in a browser. The embedded chatbot needs an internet connection.

## Service, privacy & scope

Chat conversations run through the embedded Chatbase service. Review [Chatbase's privacy policy](https://www.chatbase.co/legal/privacy) and [terms](https://www.chatbase.co/legal/terms) before use. Avoid entering sensitive or personal information.

This is a demo interface, not therapy, diagnosis, medical advice, emergency assistance, or crisis support.
